Classification des sons environnementaux

Des enregistreurs posés en forêt, à Sequoia National Park, captent en continu le paysage sonore : chants d'oiseaux, vent, insectes, mais aussi avions, voix, moteurs. Ce projet entraîne un modèle SVM à repérer, dans ces enregistrements, ce qui relève du vivant (biophonie) et ce qui relève de l'activité humaine (anthropophonie).

Carnet de méthode

Le pipeline, du fichier audio brut à l'étiquette prédite.

1

Extraction

La base SEKI regroupe des enregistrements d'une heure, pris sur 4 sites du parc à toutes les saisons, découpés en extraits de 30 secondes toutes les 5 minutes (3 842 segments labellisés au total). Chaque extrait de 30 secondes est ensuite regroupé par séquences de 6 fichiers de 5 secondes, puis transformé en spectrogramme par transformée de Fourier à court terme (STFT, hop_length 64, win_length 512).

2

Réduction

Chaque spectrogramme est projeté sur 5 composantes principales (PCA, avec whitening) pour réduire la dimensionnalité avant l'entraînement.

3

Classification

Deux SVM à noyau RBF sont entraînés séparément — un pour la biophonie, un pour l'anthropophonie — avec pondération des classes et réglage des hyperparamètres (gamma, C) par recherche sur grille, validée en 4 plis stratifiés.

4

Restitution

Les prédictions sont combinées (biophonie seule, anthropophonie seule, les deux, aucune des deux), puis reportées sur la forme d'onde du segment et exportées en CSV.

Durée des segments & type de son

La biophonie est en général mieux reconnue que l'anthropophonie, quelle que soit la durée des segments testée. Cet écart se resserre nettement sur les jeux de données répartis uniformément entre classes : une fois le déséquilibre corrigé, les deux types de sons sont classifiés avec une précision comparable.

La durée des segments joue aussi un rôle. En moyennant les résultats des jeux triés et non triés, la précision équilibrée de la biophonie passe de 0,690 (segments de 2 secondes) à 0,661 (5 secondes) puis 0,678 (10 secondes), sans tendance nette. L'anthropophonie, elle, progresse plus régulièrement avec la durée : 0,617 à 2 secondes, 0,658 à 5 secondes, puis 0,735 à 10 secondes — la meilleure performance toutes classes et durées confondues. Les sons liés à l'activité humaine semblent donc demander une fenêtre plus longue pour être identifiés de façon fiable, alors que la biophonie reste stable quelle que soit la durée choisie.

Autre constat, moins attendu : le jeu de données à distribution naturelle (non trié) généralise mieux sur le test que le jeu rééquilibré, alors que ce dernier obtient de meilleurs scores en validation croisée. Rééquilibrer les classes améliore l'apprentissage, mais semble éloigner le modèle de la distribution réelle des sons sur le terrain, ce qui pénalise sa performance sur des données non vues.

Limites & suite

La labellisation manuelle introduit un biais : les bruits de pas ont par exemple été comptés comme anthropophoniques, alors qu'ils sont difficiles à distinguer de pas d'animaux. La géophonie (vent, ruisseaux) est quant à elle présente dans la quasi-totalité des segments, ce qui a empêché de l'entraîner comme catégorie distincte plutôt que comme simple absence des deux autres. L'étude porte sur quatre sites d'un même parc, ce qui limite la généralisation à d'autres habitats ou conditions acoustiques. La classification repose enfin sur le spectrogramme brut réduit par PCA, sans descripteurs bioacoustiques dédiés, ce qui limite la finesse de détection. Une suite possible : comparer à un modèle convolutif entraîné directement sur les spectrogrammes, ou ajouter des descripteurs acoustiques spécifiques (indices de biodiversité acoustique, par exemple).

import os
import librosa
import numpy as np
import re
from collections import defaultdict
from sklearn.decomposition import PCA
from sklearn.model_selection import StratifiedKFold
from sklearn.metrics import balanced_accuracy_score
from sklearn.svm import SVC
import matplotlib.pyplot as plt
from sklearn.model_selection import GridSearchCV
import csv
from sklearn.utils.class_weight import compute_class_weight
import matplotlib.patches as mpatches
import random

# Fonction pour extraire les caractéristiques audio
def extract_spectrogram_from_folder(folder_path):
    """
    Extrait les spectrogrammes des fichiers audio dans un dossier donné.

    Parameters:
    folder_path (str): Chemin du dossier contenant les fichiers audio.

    Returns:
    tuple: Contient les spectrogrammes, les étiquettes, les chemins des fichiers et les groupes.
    """
    files = [file for file in os.listdir(folder_path) if file.endswith('.wav')]
    pattern = re.compile(r"^(.*?-\d+_[0-9]+(?:-\d+)?)")
    valid_groups = filter_valid_groups(files, pattern)

    X = []
    labels = []
    file_paths = []
    groups = []

    for group, group_files in valid_groups.items():
        for file in group_files:
            file_path = os.path.join(folder_path, file)
            y, sr = librosa.load(file_path, sr=None)
            spectrogram = np.abs(librosa.stft(y, hop_length=64, win_length=512))
            X.append(spectrogram.flatten())
            labels.append(get_label(file))
            file_paths.append(file)
            groups.append(group)

    return np.array(X), np.array(labels), np.array(file_paths), np.array(groups)

# Fonction pour vérifier et filtrer les groupes ayant exactement 6 fichiers
def filter_valid_groups(files, pattern):
    """
    Filtre les groupes valides ayant exactement 6 fichiers.

    Parameters:
    files (list): Liste des fichiers.
    pattern (Pattern): Pattern regex pour le regroupement des fichiers.

    Returns:
    dict: Dictionnaire des groupes valides.
    """
    grouped_files = defaultdict(list)
    for file in files:
        match = pattern.match(file)
        if match:
            base_name = match.groups()[0]
            grouped_files[base_name].append(file)
    
    valid_groups = {group: group_files for group, group_files in grouped_files.items() if len(group_files) == 6}
    return valid_groups

# Fonction pour obtenir les étiquettes à partir du nom de fichier
def get_label(file_path):
    """
    Extrait les étiquettes à partir du nom de fichier.

    Parameters:
    file_path (str): Chemin du fichier.

    Returns:
    tuple: Contient les étiquettes de biophonie et d'anthropophonie.
    """
    file_name = os.path.basename(file_path)
    digits = re.findall(r'\d', file_name)
    labels_biophonie = int(digits[-2])
    labels_anthropophonie = int(digits[-1])
    return labels_biophonie, labels_anthropophonie

def sort_files(files):
    """
    Sort files by the number at the end of their name.

    Args:
        files (list): List of file names.

    Returns:
        list: Sorted list of file names.
    """
    return sorted(files, key=lambda x: int(re.search(r'_(\d+)_\d+.wav$', x).group(1))) #'NoneType' object has no attribute 'group'

# Fonction pour diviser les données en ensembles d'entraînement et de test
def split_data(X, labels, groups, file_names):
    """
    Divise les données en ensembles d'entraînement et de test en respectant les groupes.

    Parameters:
    X (array): Caractéristiques.
    labels (array): Étiquettes.
    groups (array): Groupes.
    file_names (array): Noms des fichiers.

    Returns:
    tuple: Contient les ensembles d'entraînement et de test pour les caractéristiques, étiquettes, noms de fichiers et groupes.
    """
    unique_groups = np.unique(groups)
    random.shuffle(unique_groups)  # Mélanger les groupes

    group_train, group_test = np.split(unique_groups, [int(0.7 * len(unique_groups))])  # 70% train, 30% test
    train_idx = np.isin(groups, group_train)
    test_idx = np.isin(groups, group_test)

    X_train, X_test = X[train_idx], X[test_idx]
    y_train, y_test = labels[train_idx], labels[test_idx]
    file_names_train, file_names_test = file_names[train_idx], file_names[test_idx]
    groups_train, groups_test = groups[train_idx], groups[test_idx]

    return X_train, X_test, y_train, y_test, file_names_train, file_names_test, groups_train, groups_test

# Fonction pour calculer les poids de classe
def calculate_class_weights(y_train):
    """
    Calculate class weights to handle class imbalance.

    Args:
        y_train (list): List of training labels.

    Returns:
        dict: Dictionary of class weights for biophonie and anthropophonie.
    """
    class_weights_biophonie = compute_class_weight('balanced', classes=np.unique([y[0] for y in y_train]), y=[y[0] for y in y_train])
    class_weights_anthropophonie = compute_class_weight('balanced', classes=np.unique([y[1] for y in y_train]), y=[y[1] for y in y_train])
    return {0: class_weights_biophonie, 1: class_weights_anthropophonie}

from sklearn.model_selection import cross_val_score

# Fonction pour entraîner et prédire avec le modèle
def train_and_predict(X_train, y_train, X_test, file_names_test, groups_test, Ntimes=2, n_components=5):
    """
    Entraîne le modèle et prédit les étiquettes sur l'ensemble de test.

    Parameters:
    X_train (array): Caractéristiques d'entraînement.
    y_train (array): Étiquettes d'entraînement.
    X_test (array): Caractéristiques de test.
    file_names_test (array): Noms des fichiers de test.
    groups_test (array): Groupes de test.
    Ntimes (int): Nombre de types d'étiquettes.
    n_components (int): Nombre de composants pour PCA.

    Returns:
    list: Contient les étiquettes prédites.
    """
    tabBAcc = []
    cv = StratifiedKFold(4, shuffle=True)
    models = []
    true_labels_biophonie = []
    true_labels_anthropophonie = []
    predicted_labels_final = []
    pca = PCA(n_components=n_components, whiten=True)

    class_weights = calculate_class_weights(y_train)

    for label_to_train in range(Ntimes):
        print('Training model for label:', label_to_train)
        y_train_label = [y[label_to_train] for y in y_train]
        X_pca_train = pca.fit_transform(X_train)
        assert X_pca_train.shape[1] == n_components, "PCA transformation failed"
        
        tuned_parameters = {'gamma': np.logspace(-4, 4, num=9), 'C': np.logspace(-2, 4, num=7)}
        
        # Utiliser les poids de classe spécifiques pour chaque label
        clf = GridSearchCV(SVC(kernel='rbf', class_weight={i: class_weights[label_to_train][i] for i in range(len(class_weights[label_to_train]))}), 
                           tuned_parameters, n_jobs=-1, cv=cv, pre_dispatch=6, scoring='balanced_accuracy', verbose=False)
        
        # Utilisation de la validation croisée pour évaluer les performances
        cross_val_scores = cross_val_score(clf, X_pca_train, y_train_label, cv=cv, scoring='balanced_accuracy')
        print(f"Cross-validation scores for label {label_to_train}: {cross_val_scores}")
        print(f"Mean cross-validation score: {np.mean(cross_val_scores)}")
        
        clf.fit(X_pca_train, y_train_label)
        
        X_pca_test = pca.transform(X_test)
        assert X_pca_test.shape[1] == n_components, "PCA transformation on test data failed"
        y_test_pred = clf.predict(X_pca_test)
        
        if label_to_train == 0:
            for file_name, group, label_pred_biophonie in zip(file_names_test, groups_test, y_test_pred):
                predicted_labels_final.append((file_name, group, label_pred_biophonie, None))
        else:
            for idx, (file_name, group, label_pred_anthropophonie) in enumerate(zip(file_names_test, groups_test, y_test_pred)):
                predicted_labels_final[idx] = (predicted_labels_final[idx][0], predicted_labels_final[idx][1], predicted_labels_final[idx][2], label_pred_anthropophonie)

    return predicted_labels_final

# Fonction pour évaluer les prédictions
def evaluate_predictions(y_test, predicted_labels_final):
    """
    Évalue les prédictions du modèle en calculant la précision équilibrée.

    Parameters:
    y_test (array): Étiquettes de test.
    predicted_labels_final (list): Étiquettes prédites.

    Returns:
    tuple: Précision équilibrée pour la biophonie et l'anthropophonie.
    """
    true_labels_biophonie = [sous_liste[0] for sous_liste in y_test]
    true_labels_anthropophonie = [sous_liste[1] for sous_liste in y_test]
    predicted_labels_biophonie = [label_pred_biophonie for _, _, label_pred_biophonie, _ in predicted_labels_final]
    predicted_labels_anthropophonie = [label_pred_anthropophonie for _, _, _, label_pred_anthropophonie in predicted_labels_final]

    assert len(true_labels_biophonie) == len(predicted_labels_biophonie), "Mismatch in biophonie labels length"
    assert len(true_labels_anthropophonie) == len(predicted_labels_anthropophonie), "Mismatch in anthropophonie labels length"

    bacc_biophonie = balanced_accuracy_score(true_labels_biophonie, predicted_labels_biophonie)
    bacc_anthropophonie = balanced_accuracy_score(true_labels_anthropophonie, predicted_labels_anthropophonie)

    return bacc_biophonie, bacc_anthropophonie

# Fonction pour sauvegarder les prédictions dans un fichier CSV
def save_predictions_to_csv(predicted_labels_final, output_csv):
    """
    Sauvegarde les prédictions dans un fichier CSV, avec les fichiers triés par groupe.

    Parameters:
    predicted_labels_final (list): Étiquettes prédites.
    output_csv (str): Chemin du fichier CSV.
    """
    grouped_files = defaultdict(list)
    for label in predicted_labels_final:
        grouped_files[label[1]].append(label)
    
    with open(output_csv, 'w', newline='') as csvfile:
        csvwriter = csv.writer(csvfile)
        csvwriter.writerow(['File_name', 'Group', 'Predicted_Biophonie', 'Predicted_Anthropophonie'])
        for group, labels in grouped_files.items():
            sorted_labels = sorted(labels, key=lambda x: int(re.search(r'_(\d+)_\d+.wav$', x[0]).group(1)))
            for label in sorted_labels:
                csvwriter.writerow([label[0], label[1], label[2], label[3]])
    assert os.path.isfile(output_csv), "CSV file was not created successfully"
    print(f"CSV file {output_csv} created successfully")

# Fonction pour tracer les formes d'onde avec les prédictions
def plot_waveform_with_predictions(y, sr, predictions, output_file, group_name, segment_duration=5):
    """
    Trace les formes d'onde avec les prédictions et sauvegarde le graphique.

    Parameters:
    y (array): Signal audio.
    sr (int): Taux d'échantillonnage.
    predictions (list): Prédictions pour chaque segment.
    output_file (str): Chemin du fichier de sortie pour le graphique.
    group_name (str): Nom du groupe de fichiers.
    """
    plt.figure(figsize=(15, 5))
    time = np.linspace(0, len(y) / sr, len(y))
    segment_length = sr * segment_duration

    for i in range(len(predictions)):
        start = i * segment_length
        end = (i + 1) * segment_length if (i + 1) * segment_length <= len(y) else len(y)
        if predictions[i] == 0:
            plt.plot(time[start:end], y[start:end], color='red')
        elif predictions[i] == 1:
            plt.plot(time[start:end], y[start:end], color='blue')
        elif predictions[i] == 2:
            plt.plot(time[start:end], y[start:end], color='green')
        else:
            plt.plot(time[start:end], y[start:end], color='black')

    handles = [
        mpatches.Patch(color='red', label='Biophonie'),
        mpatches.Patch(color='blue', label='Anthropophonie'),
        mpatches.Patch(color='green', label='Les deux'),
        mpatches.Patch(color='black', label='Aucun des deux')
    ]
    plt.legend(handles=handles)
    plt.xlabel('Time (s)')
    plt.ylabel('Amplitude')
    plt.title(f'Waveform with Predictions for {group_name}')
    plt.savefig(output_file)
    plt.close()

def create_waveform_graphics(input_folder, output_folder, predicted_labels_final, file_names_test, groups_test, segment_duration=5, total_duration=30):
    """
    Crée les graphiques des formes d'onde pour des segments de 30 secondes.

    Parameters:
    input_folder (str): Dossier contenant les fichiers audio.
    output_folder (str): Dossier de sortie pour les graphiques.
    predicted_labels_final (list): Étiquettes prédites.
    file_names_test (array): Noms des fichiers de test.
    groups_test (array): Groupes de test.
    """
    grouped_files = defaultdict(list)
    for file, group in zip(file_names_test, groups_test):
        grouped_files[group].append(file)

    total_plots = 0  # Initialize the variable here

    for group, files in grouped_files.items():
        print(f"Processing group: {group} with {len(files)} files")

        if len(files) != total_duration / segment_duration:  
            print(f"Skipping group {group} due to incorrect number of files")
            continue

        # Sort files using the sort_files function
        files = sort_files(files)

        combined_y, combined_sr, combined_predictions = [], None, []

        for file in files:
            file_path = os.path.join(input_folder, file)  # Corrected line
            y, sr = librosa.load(file_path, sr=None)
            combined_y.extend(y)
            combined_sr = sr

            file_pred = next((pred for pred in predicted_labels_final if pred[0] == file), None)
            if file_pred:
                label_pred_biophonie = file_pred[2]
                label_pred_anthropophonie = file_pred[3]
                if label_pred_biophonie == 1 and label_pred_anthropophonie == 1:
                    combined_predictions.append(2)
                elif label_pred_biophonie == 1:
                    combined_predictions.append(0)
                elif label_pred_anthropophonie == 1:
                    combined_predictions.append(1)
                else:
                    combined_predictions.append(3)
            else:
                print(f"No prediction found for file: {file}")
                combined_predictions = []
                break

        if not combined_predictions:
            print(f"Skipping group {group} due to missing predictions")
            continue

        if combined_sr:
            segment_length = combined_sr * segment_duration
            num_segments = int(np.ceil(len(combined_y) / segment_length))
            extended_predictions = []

            segments_per_prediction = max(1, num_segments // len(combined_predictions))

            for k in range(num_segments):
                segment_index = k // segments_per_prediction
                if segment_index < len(combined_predictions):
                    extended_predictions.append(combined_predictions[segment_index])
                else:
                    print(f"Mismatch in prediction segments for group {group}")
                    extended_predictions = []
                    break

            if not extended_predictions:
                print(f"Skipping group {group} due to mismatch in extended predictions")
                continue

            output_file = os.path.join(output_folder, f"{group}.png")
            plot_waveform_with_predictions(np.array(combined_y), combined_sr, extended_predictions, output_file, group, segment_duration)
            total_plots += 1  # Increment the plot count

    print("Graphiques créés et sauvegardés avec succès dans le dossier:", output_folder)

def main():
    input_folder = "SEKI-ALL_wav/Sons_finaux_5"
    output_csv = 'predicted_labels_nt_5sec.csv'
    output_folder = "graphiques_sons_t_30s_5"
    segment_duration = 2  # Duration of each segment in seconds

    X, labels, file_names, groups = extract_spectrogram_from_folder(input_folder)
    X_train, X_test, y_train, y_test, file_names_train, file_names_test, groups_train, groups_test = split_data(X, labels, groups, file_names)
    
    predicted_labels_final = train_and_predict(X_train, y_train, X_test, file_names_test, groups_test)
    bacc_biophonie, bacc_anthropophonie = evaluate_predictions(y_test, predicted_labels_final)
    
    print(f"Train/Test split successful: {len(X_train)} train, {len(X_test)} test")
    print("Précision équilibrée pour la biophonie :", bacc_biophonie)
    print("Précision équilibrée pour l'anthropophonie :", bacc_anthropophonie)

    save_predictions_to_csv(predicted_labels_final, output_csv)
    
    # Trier les prédictions selon le numéro du fichier dans le nom du fichier
    sorted_predicted_labels_final = sorted(predicted_labels_final, key=lambda x: int(re.split(r'_|-', x[0])[5]))
    
    # Extraire les noms de fichiers triés et les groupes
    sorted_file_names_test = [item[0] for item in sorted_predicted_labels_final]
    sorted_groups_test = [item[1] for item in sorted_predicted_labels_final]

    create_waveform_graphics(input_folder, output_folder, sorted_predicted_labels_final, sorted_file_names_test, sorted_groups_test)

if __name__ == "__main__":
    main()
