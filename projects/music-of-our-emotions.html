Music Of Our Emotions

Projet open source : à partir de signaux physiologiques, extraction de features, prédiction de dimensions émotionnelles, puis génération d’une proposition musicale (démo audio incluse).

Python ML Feature engineering Affective computing Génération musicale
Code (GitHub) Slides (PDF)
Objectif

Transformer un signal brut (physio) en information exploitable : état émotionnel → décision de génération musicale.

Pipeline

Prétraitement → features → entraînement/évaluation → prédiction → mapping / génération → rendu audio.

Résultats

Résumé des performances + exemple de rendu (audio). (Ajoute ici 1–2 métriques quand tu veux.)

Démo audio
Démo offline reproductible : VAD → émotions → prompt → rendu audio. (Acquisition temps réel non incluse : matériel requis.) Prompt (extrait) : “Une musique avec 59.3% annoying, 20.1% anxious, 12.7% erotic.”
Limites & suite

Généralisation inter-individus, bruit/variabilité, évaluation utilisateur. Suite : calibration perso, modèles séquentiels, et critères musicaux plus stricts (cohérence, structure).
