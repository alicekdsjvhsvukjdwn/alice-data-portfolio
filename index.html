🚋 Projet RTM – Digitalisation du réseau Tram

Python Power BI Geo / PK
Stage – RTM, Marseille (2025)

Problème. Données tram multi-sources (Excel/GPS) hétérogènes → difficile à exploiter pour piloter la maintenance.

Approche.

  • Consolider les sources + normaliser un référentiel (PK / voie / ligne)
  • Mettre des contrôles qualité (dédoublonnage, cohérence PK, complétude)
  • Rendre visible via carte (Leaflet) + dashboard (Power BI)

Livrables. Pipeline Python + référentiel propre + carte interactive + dashboard.

Impact. Données plus fiables + lecture plus simple pour les équipes (tech + pilotage).

Décisions facilitées.

  • Identifier rapidement zones / points incohérents
  • Prioriser les vérifications et interventions terrain
  • Suivre l’état d’avancement (qualité, complétude)

Stack. pandas / geopandas / openpyxl · Power BI · Leaflet · GitHub

🎟️ Mini-projet – Pilotage billetterie (cas “festival / salle”)

Projet personnel (2026) — KPI • segmentation • recommandations

Objectif. Proposer un tableau de bord simple pour suivre la performance billetterie et comprendre les publics (sans jargon, utilisable en prod).

Indicateurs suivis.

Ventes / jour Taux de remplissage Panier moyen Canaux (web/partenaires) Tarifs No-show (si applicable)

Segmentation.

Par type de public (local/touriste), prix, timing d’achat (early/late), et/ou zones géographiques. But : savoir quoi pousser et où.

Livrables.

  • 1 dashboard (Power BI / Excel) : vue direction + vue opérationnelle
  • 1 note de synthèse : 5 insights + 5 actions recommandées
  • 1 check qualité data : doublons, valeurs manquantes, cohérence dates/tarifs

Statut : en cours — j’ajoute bientôt une capture + un exemple de dashboard (même sur données fictives).
